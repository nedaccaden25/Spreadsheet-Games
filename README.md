# Spreadsheet-Games
A collection of recreations of classic games within Google Sheets (and some of my first actual coding projects so some things are pretty gross and poorly optimized)
# Snake
As it turns out, applying the visual changes to the sheet takes quite a long time, so the snake moves pretty slow... But it's perfectly functional snake other than that. Controlled by checking 4 different checkboxes on the sheet corresponding to each direction. Each apple collected increases the snake's length by one and collisions with the body or the wall will end the game. Keeps track of high score. Unfortunately Google's scripts will only run for a maximum of 5 minutes, and if this time is exceeded then the script ends prematurely. I was unaware of this when making this game, so playing it for longer than 5 minutes is impossible.
# Minesweeper
Makes a minesweeper board ranging from 1x1 to 20x20 with a specified # of mines. The data for which cells are mines is stored within the cells themselves by using 0xFFFFFE for their color instead of 0xFFFFFF which is effectively indistinguishable. Clicking a non-dug space and then clicking the dig button digs up the space. The number of mines next to the space is calculated when the space is dug, and if the number is 0 then all the surrounding spaces will be recursively dug. The flag button simply colors the selected space 0xEA9999 if it didn't have a mine or 0xEA9998 if it did have a mine. The flags can also be removed by pressing the flag button again.
# Connect 4
Since this function also runs indefinitely it is also subject to the 5-minute limit. The button clears the board and makes the selected player go first (there is a checkbox for who goes first). The board is 6 cells tall and 7 cells wide. The player chooses where to drop a piece by checking one of 7 boxes above each column. The piece will visually fall from the top until it reaches another piece and the box will be unchecked before allowing the next player to make their move. If the placed piece creates a four-in-a-row in any direction the game will immediately end and declare the last player who dropped a piece the winner. Due to the cloud-based nature of google sheets, one user can start the game on one device while the second player accesses the sheet through a different device and both players can see the changes being made at the same time.
# Yahtzee
This game has 5 different ways to be played, the standard game can be played with up to 4 people (who can be on different devices as explained in Connect 4), or a single player can play Triple Yahtzee which works the same as normal Yahtzee except there are three identical columns in the score sheet and any of them can be chosen to score in for any roll, but the second and third columns have score multipliers of X2 and X3 respectively. The roll button will roll all 5 dice if this is the first roll attempt, but the second and third attempts will only roll dice that don't have the "keep" checkbox checked, and any attempts past the third will do nothing, if the previous game has already been finished then the roll button will do nothing. The dice are displayed as 3x3 sets of black cells that are filled with 1-6 of this character: • to recreate how real dice look. Each scoring row on the sheet has its own button and automatically fills the corresponding box (if playing Triple Yahtzee three checkboxes will be shown that correspond to each column and exactly one of these must be checked and this row will be scored in the selected column). When the last row is checked for the last player the game will end. Since some Yahtzee games can have weird outcomes, an extra page on the sheet was made to store up to 4 games in slots specified by a drop down selection. The total high score for both normal and Triple Yahtzee is kept track of on the main page. The reason each type of scoring has its own function is due to them being tied to different buttons on the sheet, however this is really annoying since you have to grant permissions to each unique function, so I would set this up differently if I were to redo it.
