# Spreadsheet-Games
A collection of recreations of classic games within Google Sheets (and some of my first actual coding projects so some things are pretty gross and poorly optimized). Here are the details of each game in the order they were made.
# Snake
As it turns out, applying the visual changes to the sheet takes quite a long time, so the snake moves pretty slow... But it's perfectly functional snake other than that. Controlled by checking 4 different checkboxes on the sheet corresponding to each direction. Each apple collected increases the snake's length by one and collisions with the body or the wall will end the game. Keeps track of high score. Unfortunately Google's scripts will only run for a maximum of 6 minutes, and if this time is exceeded then the script ends prematurely. I was unaware of this when making this game, so playing it for longer than 5 minutes is impossible.
# Minesweeper
Makes a minesweeper board ranging from 1x1 to 20x20 with a specified # of mines. The data for which cells are mines is stored within the cells themselves by using 0xFFFFFE for their color instead of 0xFFFFFF which is effectively indistinguishable. Clicking a non-dug space and then clicking the dig button digs up the space. The number of mines next to the space is calculated when the space is dug, and if the number is 0 then all the surrounding spaces will be recursively dug. The flag button simply colors the selected space 0xEA9999 if it didn't have a mine or 0xEA9998 if it did have a mine. The flags can also be removed by pressing the flag button again.
# Connect 4
Since this function also runs indefinitely it is also subject to the 6-minute limit. The button clears the board and makes the selected player go first (there is a checkbox for who goes first). The board is 6 cells tall and 7 cells wide. The player chooses where to drop a piece by checking one of 7 boxes above each column. The piece will visually fall from the top until it reaches another piece and the box will be unchecked before allowing the next player to make their move. If the placed piece creates a four-in-a-row in any direction the game will immediately end and declare the last player who dropped a piece the winner. Due to the cloud-based nature of google sheets, one user can start the game on one device while the second player accesses the sheet through a different device and both players can see the changes being made at the same time. While using the cells directly doesn't look very good, placing an image of a blue square with several transparent circles in it gives the illusion that the cells are circular in shape.
# Yahtzee
This game has 5 different ways to be played, the standard game can be played with up to 4 people (who can be on different devices as explained in Connect 4), or a single player can play Triple Yahtzee which works the same as normal Yahtzee except there are three identical columns in the score sheet and any of them can be chosen to score in for any roll, but the second and third columns have score multipliers of X2 and X3 respectively. The roll button will roll all 5 dice if this is the first roll attempt, but the second and third attempts will only roll dice that don't have the "keep" checkbox checked, and any attempts past the third will do nothing, if the previous game has already been finished then the roll button will do nothing. The dice are displayed as 3x3 sets of black cells that are filled with 1-6 of this character: • to recreate how real dice look. Each scoring row on the sheet has its own button and automatically fills the corresponding box (if playing Triple Yahtzee three checkboxes will be shown that correspond to each column and exactly one of these must be checked and this row will be scored in the selected column). When the last row is checked for the last player the game will end. Since some Yahtzee games can have weird outcomes, an extra page on the sheet was made to store up to 4 games in slots specified by a drop down selection. The total high score for both normal and Triple Yahtzee is kept track of on the main page. The reason each type of scoring has its own function is due to them being tied to different buttons on the sheet, however this is really annoying since you have to grant permissions to each unique function, so I would set this up differently if I were to redo it.
# Checkers
Generating a new board creates an 8x8 checkerboard where half the tiles are gray and the other half are red/white/blue (depending on what piece is in each spot) with a checkbox. The "Make Move" button checks to see if the active player's color has exactly one piece selected and they've also selected where to move that piece to. Valid moves are as follows: One of the two spaces directly in front of the piece (up for red, down for blue) so long as that space is unoccupied, if that space is occupied by an enemy piece then the space one beyond that space is valid. For kings (denoted by being a darker shade of red or blue) both directions are considered valid. Multiple jumps can be made by selecting each space that is landed on between jumping over each space, and kings may jump forwards and backwards in the same movement. After the move is made, all the checkboxes associated with that move will be unchecked and the next player's turn will begin unless they are out of pieces. This system does break down if multiple valid moves are selected when the "Make Move" button is pressed, as it will only make one of the moves and the unchosen checkbox will remain checked after the move is done. Invalid boxes can also be checked so long as there is a valid move to make and the invalid checkboxes will remain checked. This system doesn't detect when a player is unable to move, so a forfeit button was added so that a winner can always be officially declared. This system also doesn't force captures if they are available since this rule is often omitted by players.
# Stratego
This game has the most complex rules out of all the games I have made. The board is 8x10 spaces and there are two 2x2 lakes centered in the 3rd and 4th as well as the 7th and 8th columns that cannot be moved into by any piece. Both players have 30 preset pieces that can be placed anywhere in their side's closest 3 rows, however only the player controlling the pieces knows what they actually are. Due to this secrecy, players play on two different pages of the sheet where only their own pieces are labelled and both are updated as turns are taken. Firstly, each player goes to a different page to assemble their pieces on the board by typing the numbers 1-10 or the letters "F", "B", or "S" directly onto the desired spaces. Once the board is created it must first be validated to make sure the correct amounts of each piece are used, then the board can be submitted. Once both players have submitted their board, the red player takes the first turn by selecting a piece. Selecting a piece darkens it on both players' pages which helps to keep track of which piece is currently moving since movements can be hard to track on the sheet. Once a piece is selected it can be moved into any adjacent space with the following exceptions: The space to move to cannot be a part of the lakes or another one of your pieces, "F" and "B" pieces cannot move, "2" pieces can move any amount of spaces in one direction at a time. If a piece moves directly onto another piece they fight. The winner of the fight remains on the contested space while the loser is removed from the game. The outcomes of a fight are as follows: the higher number will always win, "B" pieces always win unless their opponent is a "3", "S" pieces always lose unless they are the initiator of the combat AND their opponent is a "10", "F" pieces always lose and if this piece is taken then its owner loses the game, If the two pieces are the same they are both removed from the game. After combat has been resolved, the results are displayed for both players and the tracker of lost pieces below the board is updated. The strangest piece is the "1" piece which can choose to "spot" a piece after/instead of moving. To spot a piece it must be directly in front of the "1" piece (up for red, down for blue) and the controller of the "1" piece must make a guess as to what the opponent's piece is. If the guess is correct then the "spotted" piece is removed from the game, otherwise nothing happens. After moving a "1" piece if there is a valid piece to spot the player who moved the piece will be asked if they want to attempt to spot the piece, if so they must place their guess in the corresponding box and check the box, at which point the effects of the spot will be resolved and the results will be displayed for both players. To spot without moving the spotter must be attempt to move onto the spot it's already on, at which point its controller will be asked if they want to attempt to spot, and if they don't want to spot, then their turn will not end since one piece must be moved every turn unless they choose to spot. This game has two win conditions, capturing the opponent's "F" piece, or forcing their opponent into a situation with no legal moves, however this system does not check for the second case and the game will get stuck waiting for the losing player to make a move.
# Sudoku
This Sudoku player is not very sophisticated, since the way boards are generated is by selecting 1 out of 100 pre-solved sudoku boards and randomly removing numbers from it, only leaving an amount depending on the selected difficulty (or a custom amount). The board can also be checked to see if the current board state has any errors. If there is a duplicate number in a row/column/box, then both numbers will be colored red. Since this red color is not removed when the cells' values are updated there is a separate function that re-colors all of the cells white.
# Solitaire
This game utilized the visual aspects of Google sheets to actually look like cards on a board by merging cells and putting borders between overlapping cards. When a new game is generated, 7 columns of cards are laid out with each column getting one more than the last and only the top-most card is face-up. Any remaining cards are added to the stockpile deck. Since the card values are not directly shown to the player, they must be stored elsewhere on the sheet, which in this case the relevant data is stored 800 cells below the game as white text to perfectly blend in. When Cards are drawn from the stockpile, either 1 or 3 are drawn at a time, specified in a drop down before the game begins. If 3 cards are drawn at a time then only the top-most card can be moved. When the stockpile is out of cards, the draw button will instead re-stack the drawn cards into the stockpile in the same order they were drawn in. When selecting a card to move, it will turn red and then can be moved on top of a card so long as that card is one higher in value and is the opposite color. Cards can instead be moved to the upper-left where there are four spots corresponding to each suit and a card can be placed there so long as it is one greater than the card currently shown there. A card can be moved even if it is not on the top of its stack, in which case all the cards on top of it will be moved with it to the same location. # Battleship
Due to not knowing the opponent's board setup, this game uses a similar structure as Stratego where each player has their own page of the sheet to play on, however the game is both set up and played on the same sheet. First both players directly type letters into cells to indicate where their boats should be placed, then both players check to make sure their board state is valid such that each boat is continuous and is the correct length. Player 1 then begins the game by pressing the "Start Game" button where the code will then run continuously in the background. Of the two 10x10 grids shown on each player's page, one of them shows their current ship layout and the other is full of checkboxes which the active player will check to try to hit the opponent's ships. If a hit was scored, the active player may shoot again, with a special message being displayed for fully sinking a boat. Since this function runs indefinitely in the background, it is subject to the 6-minute limit, however there is another button that is used to continue a game if one ended prematurely.
